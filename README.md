# SafeSphere promotional website

NEX3 — Team 7 · University of Sunderland · CET257.

Browser-based promotional prototype. See A6_ALIGNMENT.md for mapping to the supplied assessment document and verification limits.

## Run
Use Node.js 22 and npm. Run `npm ci`, then `npm run build` and `npm run dev`. The dev command serves the static export from `out`. Rebuild after changing source. No database, environment secrets or accounts are required.

## Demo
Open the home page or Training → Hazard Perception, inspect the fictional observation and select a response. Reset to retry. For Trainees shows the proposed 12-stage learner journey. Login and Contact demonstrate UI state only; use fictional details. They do not authenticate, send requests or save submitted data.

## Branding
The supplied PNG is preserved intact. All shared branding uses it. The animated model echoes its shield ribbon, blue globe and cyan orbit. Motion can be paused and respects the reduced-motion preference. The supplied tagline is aspirational; it does not guarantee safety outcomes.
