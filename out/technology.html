Stack overview

What each layer is responsible for.

Next.js + React + TypeScript

Application foundation, typed component architecture and responsive product surfaces.

React Three Fiber + Three.js

Browser-based 3D environments and interactive scenario layers.

NestJS

Proposed backend architecture for APIs, training workflows and application logic.

PostgreSQL + Prisma

Structured persistence for training records, learner data and scoring-related information.

Server-Side Scoring

Outcome logic is designed around structured server-side processing rather than relying only on the client.

Desktop Browser MVP

The immediate experience targets desktop browsers, with future WebXR/VR exploration as a direction.

Results need a trusted source.

The planned training application sends each learner action to the server. The server determines correctness, scores and critical outcomes; the browser displays the returned result.

Role-based permissions are planned for trainees, trainers and administrators. JWT authentication and REST/OpenAPI services belong to the proposed application architecture, not this demonstration site.
